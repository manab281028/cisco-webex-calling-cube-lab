# Troubleshooting Experience

The project also strengthened my troubleshooting skills by resolving issues such as:

- SIP Registration failures
- Phone Services disconnected
- Softphone registration issues
- Internal call failures
- PSTN routing problems
- Twilio Error 21264 (Caller ID verification)
- Call routing validation

---

# Key Takeaways

- Always verify SIP registration before troubleshooting call routing.
- Validate user licensing and provisioning before investigating client-side issues.
- Confirm dial peer matching and destination patterns during call routing.
- Use both Cisco CLI and Control Hub to validate deployment status.
- Follow a structured troubleshooting methodology to isolate issues efficiently.

# Outcome

This project successfully demonstrated a complete Cisco Webex Calling deployment with secure SIP signaling, internal extension calling, and PSTN integration using Cisco Catalyst 8000V (CUBE) and Twilio.

The implementation improved my practical knowledge of Cisco Collaboration technologies and strengthened my ability to deploy, validate, and troubleshoot enterprise voice solutions.
